# Genova Offline UI

این پوشه یک UI مستقل و آفلاین با زبان Python است. هیچ فایل یا کتابخانه‌ای از اینترنت در زمان اجرا دریافت نمی‌شود.

## اجرا

در همین پوشه یا از ریشه پروژه:

```bash
python emergency/app.py
```

سپس در مرورگر باز کنید:

```text
http://127.0.0.1:8765
```

برای توقف سرور `Ctrl+C` بزنید.

## ساختار

- `app.py`: سرور سبک Python با کتابخانه استاندارد
- `static/style.css`: طراحی RTL، راست‌چین و واکنش‌گرا
- `static/app.js`: تعاملات سبک رابط کاربری
- فایل‌های HTML و CSS و JavaScript همگی محلی هستند و هیچ CDN یا لینک خارجی ندارند.

## وضعیت این مرحله

این مرحله فقط UI نمایشی است و هیچ داده‌ای از سایت اصلی، محتوای دوره، ورود کاربر، دیتابیس یا API سایت را دریافت نمی‌کند. سایت اصلی نیز تغییری نکرده است.
