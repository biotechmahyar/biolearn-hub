## 🚀 نصب

### روش ۱: آپلود از پنل وردپرس (توصیه شده)

#### مرحله ۱: قالب را زیپ کنید
```bash
cd wordpress-nibrc
zip -r nibrc-theme.zip nibrc-theme/
```

#### مرحله ۲: آپلود قالب
1. وارد پنل وردپرس شوید
2. از منوی **ظاهر → پوسته‌ها → افزودن پوسته جدید**
3. روی **بارگذاری پوسته** کلیک کنید
4. فایل `nibrc-theme.zip` را انتخاب کنید
5. روی **نصب** و سپس **فعال‌سازی** کلیک کنید

#### مرحله ۳: افزونه سینک (اختیاری)
1. از منوی **افزونه‌ها → افزودن**
2. فایل `nibrc-sync/nibrc-sync.php` را آپلود کنید
3. فعالش کنید

### روش ۲: آپلود دستی از File Manager

فایل‌ها را مستقیماً به پوشه‌های زیر در هاست آپلود کنید:

```
/public_html/wp-content/themes/nibrc-theme/
/public_html/wp-content/plugins/nibrc-sync/
```

## ⚙️ تنظیمات اولیه

### ۱. صفحات مورد نیاز
از منوی **صفحه‌ها → افزودن** این صفحات را بسازید:

| عنوان صفحه | نام قالب |
|-----------|---------|
| ورود | Auth Page |
| داشبورد | Dashboard |
| دیکشنری | Dictionary |
| آزمون‌ها | Exams |
| قوانین | پیش‌فرض |

### ۲. نمایش صفحه اصلی
1. از منوی **تنظیمات → خواندن**
2. **صفحه اصلی نمایش داده شود: صفحه ثابت**
3. صفحه اصلی (WordPress page) را انتخاب کنید

### ۳. بازنویسی لینک‌ها
1. از منوی **تنظیمات → پیوندهای یکتا**
2. **نام سفارشی** را انتخاب کنید
3. مقدار: `%postname%`

### ۴. منوی ناوبری
1. از منوی **ظاهر → فهرست‌ها**
2. یک فهرست جدید با نام "منوی اصلی" بسازید
3. لینک‌ها را اضافه کنید:
   - خانه → `/`
   - دوره‌ها → `/courses`
   - مقالات → `/articles`
   - اساتید → `/instructors`
   - محصولات → `/products`
   - دیکشنری → `/dictionary`
   - آزمون‌ها → `/exams`

### ۵. تنظیم سینک
1. از منوی **تنظیمات → سینک NIBRC**
2. آدرس سایت اصلی: `https://nibrc.ir`
3. کلید سینک را از پنل مدیریت سایت اصلی بگیرید
4. فاصله سینک را تنظیم کنید (پیشنهاد: ۳۰ دقیقه)
5. ذخیره و سینک فوری بزنید

## 📝 ایجاد محتوا

### دوره‌ها
1. از منوی **دوره‌ها → افزودن دوره**
2. عنوان، توضیحات، تصویر شاخص
3. در باکس **جزئیات دوره**: قیمت، استاد، مدت، سطح، جلسات
4. ذخیره

### مقالات
1. از منوی **مقالات → افزودن مقاله**
2. عنوان، محتوا، تصویر شاخص
3. دسته‌بندی انتخاب کنید

### اساتید
1. از منوی **اساتید → افزودن استاد**
2. نام، بیوگرافی، تخصص، عکس پروفایل

### دیکشنری
1. از منوی **دیکشنری → افزودن اصطلاح**
2. نام اصطلاح، نام لاتین، توضیحات
3. دسته‌بندی، زیستگاه، نیاز اکسیژن

### آزمون‌ها
1. از منوی **آزمون‌ها → افزودن آزمون**
2. عنوان، مدت، نمره قبولی
3. سوالات را به صورت JSON در باکس مخصوص وارد کنید

## 🔐 احراز هویت

- **ورود/ثبت‌نام**: از صفحه `/auth` با فرم‌های AJAX
- **JWT**: توکن‌های ساده در localStorage ذخیره می‌شوند
- **ادمین**: نقش `administrator` در وردپرس
- **استاد**: نقش `instructor` در وردپرس

برای ایجاد نقش استاد، از افزونه **User Role Editor** استفاده کنید اا مستقیماً در دیتابیس اضافه کنید.

## 🔄 سینک با سایت اصلی

### سینک خودکار
هر ۳۰ دقیقه (قابل تنظیم) از سایت اصلی داده‌ها را دریافت و بروزرسانی می‌کند.

### سینک دستی
از صفحه تنظیمات سینک، دکمه **سینک فوری** را بزنید.

### push تغییرات آفلاین
وقتی اینترنت برگشت، ثبت‌نام‌های آفلاین به سایت اصلی ارسال می‌شوند.

## 🌐 وضعیت اتصال

نوار بالای سایت وضعیت اتصال را نشان می‌دهد:
- 🟢 **سبز**: اتصال برقرار — سایت آنلاین
- 🟡 **زرد**: اتصال قطع — حالت آفلاین

## 📱 ریسپانسیو

قالب کاملاً ریسپانسیو است و در موبایل، تبلت و دسکتاپ نمایش درستی دارد.

## 🔧 سفارشی‌سازی

### تغییر رنگ‌ها
فایل `style.css` → بخش `:root` را ویرایش کنید:

```css
:root {
  --nibrc-primary: #059669;     /* رنگ اصلی */
  --nibrc-primary-dark: #047857; /* رنگ تیره‌تر */
  --nibrc-accent: #f59e0b;      /* رنگ اکسنت */
}
```

### تغییر فونت
در `functions.php` → `nibrc_scripts()` فونت Google را تغییر دهید.
